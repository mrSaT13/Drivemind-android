# Источники данных и права

## Билеты ПДД / знаки / штрафы
Часть материалов в `assets/data/` и `assets/images/` производна от открытого
репозитория **etspring/pdd_russia** (https://github.com/etspring/pdd_russia):
билеты 1–40 (категории A/B), знаки, разметка, штрафы.

ВАЖНО:
- У репозитория-источника **нет файла LICENSE** (проверено 15.09.2026 через
  GitHub API — 404 на /license). Значит по умолчанию действует
  «все права защищены», свободной лицензии НЕТ.
- Сам текст ПДД РФ как нормативный акт авторским правом не охраняется
  (ст. 1259 ГК РФ). Но конкретные формулировки вопросов, подсказки
  («answer_tip»), подборки, описания знаков и фотографии/рисунки МОГУТ
  принадлежать авторам источника или третьим лицам.
- Автор источника в README прямо указывает нюансы: topic стал массивом,
  id = MD5(question+answers), один вопрос может встречаться в разных
  разделах/категориях с разными картинками. Это подтверждает, что данные —
  результат чужой обработки, а не «голый» официальный текст.

## Что это значит для публикации
1. **Приватный репозиторий / учёба — ок.** Оставь этот NOTICE + ссылку на источник.
2. **Публичный GitHub + Google Play — РИСК.** Перед открытием нужно:
   а) получить письменное разрешение автора etspring, ИЛИ
   б) заменить контент на заведомо чистый: официальные тексты ПДД с
      consultant.ru / pravo.gov.ru + свои формулировки вопросов и свои/открытые
      изображения (свои фото, Wikimedia Commons с CC0/CC-BY, нейросеть).
3. Картинки с хэш-именами (`a892d06d....jpg`) без метаданных лицензии —
   самые рискованные. Проверь каждую или замени.
4. Добавь в приложение экран «О приложении» с дисклеймером:
   «Не является официальным приложением ГИБДД/МВД. Материалы для подготовки,
   сверяйтесь с официальными билетами. Источник части материалов:
   github.com/etspring/pdd_russia».
